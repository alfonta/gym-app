# פצצת הבנטו 🍱

משחק שיתופי לשניים: אחד רואה את הבנטו על המסך, השנייה מחזיקה את מדריך הפירוק בטלפון. רק בדיבור אפשר לנטרל.

## קישורים

- המשחק: `https://<user>.github.io/<repo>/`
- המדריך: `https://<user>.github.io/<repo>/manual.html`

(יעודכן אחרי הפריסה. הקוד QR במסך הפתיחה מוביל תמיד למדריך שבאותה כתובת.)

## הכנה לערב משחק

1. מחברים את המחשב הנייד לטלוויזיה בכבל HDMI (או משדרים את הלשונית מ־Chrome).
2. פותחים את המשחק ולוחצים "מסך מלא".
3. המומחה/ית סורק/ת את קוד ה־QR בטלפון ופותח/ת את המדריך.
4. המומחה/ית יושב/ת **עם הגב לטלוויזיה**. המנטרל/ת מחזיק/ה את העכבר.
5. מתחילים ברמה "קל". אפשר גם להתאמן קודם על חידה אחת בלי לחץ ("אימון").

אפשר להדפיס את המדריך (A4) במקום להשתמש בטלפון.

## הרצה מקומית

מודולי ES לא נטענים מ־`file://`, ולכן צריך שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000/
```

- `?seed=123` — משחזר בנטו מסוים.
- `?debug=1` — מציג את הפתרון של כל חידה (לבדיקות לבד).

## בדיקות

```bash
node --test tests/logic.test.mjs
```

## מבנה

- `index.html` + `js/bomb.js` + `js/modules-ui.js` — הבנטו.
- `manual.html` + `js/manual.js` — המדריך. הטבלאות נבנות מאותם נתונים שבהם משתמש `solve()`, כך שהמדריך והמשחק לא יכולים לסתור זה את זה.
- `js/logic/` — לוגיקה טהורה בלי DOM (מחוללים, כללים, `solve()`), נבדקת ב־Node.
- `js/vendor/qrcode.js` — ספריית QR (רישיון MIT, Kazuhiko Arase).
